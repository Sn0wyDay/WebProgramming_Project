# RE:VERSE

웹프로그래밍 수업에서 만든 음악 감상 기록 서비스입니다. 좋아하는 가사 한 줄을 골라 그때 든 생각을 적고, 친구와 서로의 감상을 나눌 수 있습니다.

## 실행 방법

Python 3.9 이상이 필요합니다. Mac에서는 프로젝트 폴더에 있는 **REVERSE 실행.command**를 더블클릭하면 브라우저가 열립니다. 처음 실행할 때는 필요한 라이브러리를 설치하므로 인터넷에 연결해 주세요. 사용하는 동안에는 실행 창을 열어 두고, 끝나면 `Ctrl+C`로 종료합니다.

터미널을 사용한다면 프로젝트 폴더에서 아래 순서로 실행합니다.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

Windows 명령 프롬프트에서는 첫 줄을 `py -m venv .venv`, 둘째 줄을 `.venv\Scripts\activate.bat`로 바꾸면 됩니다. 서버가 켜지면 브라우저에서 [RE:VERSE 홈](http://127.0.0.1:5001)을 엽니다.

## 사용 방법

1. 회원가입 후 홈에서 **추가**를 누릅니다. **외부 음악**에서 곡을 찾거나 **저장된 음악·가사**에서 이미 불러온 곡을 찾을 수 있습니다.
2. 가수와 제목을 모두 알고 있다면 검색 기준을 **가수 + 곡 제목**으로 바꿉니다. 예를 들어 가수 칸에 `정승환`, 제목 칸에 `눈사람`을 입력하면 두 조건으로 검색합니다.
3. 곡을 열고 마음에 드는 가사 한 줄을 누르면 작성 칸이 열립니다. 감상을 저장하면 그 구절 바로 아래에 표시됩니다. 쓴 글은 다시 수정하거나 삭제할 수 있습니다.
4. 다시 듣고 싶은 곡은 북마크를 눌러 저장합니다. 저장하면 북마크가 초록색으로 채워집니다. 곡에 별점을 주거나 **나의 기록**에서 이전 감상을 찾아볼 수도 있습니다.
5. 친구 화면에서 이름이나 아이디로 친구를 찾습니다. 상대가 요청을 수락하면 **친구에게 공개**로 남긴 감상을 서로 볼 수 있습니다. **나만 보기**로 쓴 글은 본인만 볼 수 있습니다.

## 음악 자료

곡과 앨범 정보는 [MusicBrainz](https://musicbrainz.org/), 가사는 [LRCLIB](https://lrclib.net/), 앨범 표지는 [Cover Art Archive](https://coverartarchive.org/)에서 가져옵니다. 곡이나 앨범에 관련된 글이 있으면 상세 화면에서 원문을 열 수 있습니다. 평론은 [IZM](https://www.izm.co.kr/), 연말 선정 기사는 [HELLOKPOP](https://www.hellokpop.com/)에서 찾습니다.

검색되는 곡이라도 가사가 아직 등록되지 않았거나 제목 표기가 달라 가사를 찾지 못할 수 있습니다. 연결 오류가 뜨면 잠시 뒤 다시 조회해 주세요. 표지가 없는 곡에는 기본 이미지가 나오고, 관련 평론을 찾지 못하면 ‘등록된 평론이 없습니다.’라고 표시됩니다.

## 개발 환경

화면은 HTML, CSS, JavaScript로 만들었고 서버는 Flask를 사용합니다. 계정과 감상 기록은 프로젝트 폴더의 `instance/preview.db`에 SQLite로 저장됩니다. 서버를 껐다 켜도 기록이 남으므로, 기록을 보관하려면 이 파일을 함께 보관해 주세요.

기본 실행에는 API 키가 필요 없습니다. 음악 추천은 내 음악 기록과 선택한 장르를 바탕으로 MusicBrainz에서 후보를 조회합니다. 포트 같은 설정은 [.env.example](.env.example)을 참고하세요.

테스트는 가상환경을 켠 상태에서 실행합니다.

```sh
pip install -r requirements-dev.txt
python -m pytest -q
```

홈과 곡 상세 화면의 파일 위치, 팀원 페이지와 연결하는 방법은 [홈 담당 인수인계 문서](docs/HOME_HANDOFF.md)에 정리했습니다.
